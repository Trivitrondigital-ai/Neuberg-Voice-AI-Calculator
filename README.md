# Neuberg-Voice-AI-Calculator

Live calculator: https://trivitrondigital-ai.github.io/Neuberg-Voice-AI-Calculator/

Static HTML calculator hosted with GitHub Pages. Open `index.html` locally, or visit the live link. Excel exports run in the browser. Google Fonts uses system fonts as a fallback.

To update, replace `index.html`, commit and push to `main`. GitHub Pages publishes from the repository root.
